# AYV WRLD

Single-page studio site for AYV WRLD. Next.js 14, Tailwind CSS, and Framer Motion.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Edit copy and links

Search the project for `PLACEHOLDER`.

- Wording and URLs: `lib/site.ts`
- Dili Paints screenshot: `components/CaseStudies.tsx`
- Kleuro logomark: `components/Products.tsx` (drop files in `public/logos/` when ready)
- Waitlist and contact forms have no backend yet

Logos live in `public/logos/`. White marks are used on dark surfaces and black marks on light surfaces.
